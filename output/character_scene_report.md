## 4. 配樂與音效來源

**沒有使用任何下載或第三方的音樂、音效。** 全部用 `scripts/audio.py` 以 numpy/scipy 合成（振盪器、濾波雜訊、卷積殘響），是原創內容，不涉及授權問題。

- **配樂**（D 小調，96 BPM，Dark cinematic electronic）
  - 開場：低頻 drone、sub 脈衝、帶回音的 pluck
  - 搗蛋鬼段：不規則方波 blip 和 swing hi-hat
  - 英雄段：半拍深鼓、穩定的八分音符低音、暗色和弦（Dm → B♭）
  - 笑容停住：配樂抽空
  - 撞擊：riser，接 17.10 重拍（sub drop、銅管感和弦、cymbal wash）
  - 資訊卡：低調收尾律動，合併兩人主題（D 小調墊底、sub 脈衝、柔和半拍鼓、稀疏電子 blip），比對白段低約 8 dB，方便閱讀
  - 結尾：24.15 秒一記短擊加和弦，殘響在 25.0 秒前收完
  - 沒有任何人聲或歌詞
- **音效**：whoosh、電子 glitch stinger、cinematic impact、披風風聲、細微 glitch、漫畫撞擊＋低頻衝擊、資訊卡落下 slap、「神秘小禮」四個 pop。
  - 需求中「最後定格的短促 impact 與殘響」和「對峙撞擊」合併在 17.10 同一擊，之後的殘響就是定格的收尾。避免兩次撞擊太近、互相搶戲。
- **混音**
  - 兩段配音先調到同樣的語音響度。
  - 有人說話時配樂自動壓低約 9 dB（ducking：起音 40 ms、釋放 350 ms）。
  - 對白期間配音比配樂高約 14–20 dB。
  - 所有音效事件都加了 1 ms 淡入、6 ms 淡出，避免爆音。

## 6. 已知限制與可調整處

- 角色原圖每格約 600 px，近景放大 2–3 倍。用了 Lanczos 縮放和輕度銳化，線條清楚，但細節不如原生高解析度的圖。
- 畫面有雨絲、網點和顆粒，碼率需求較高。正式版用 CRF 19，上限 18 Mbps，以控制檔案大小。
- 「KRAK!」是新增的擬聲字，已依確認的分鏡 v2 加入。若要拿掉，把 `scripts/scene.py` 的 `LETTERING` 改成 `"subtitle"`，就會回到一般字幕、不加擬聲字的版本。

## 7. 重新產生

```bash
pip install opencv-python-headless scipy pyloudnorm pillow numpy
# 字型放到 output/_build/fonts/：
#   NotoSansTC.ttf      ← google/fonts ofl/notosanstc/NotoSansTC[wght].ttf

python3 scripts/cutout.py          # 切四格並去背
cd scripts
python3 storyboard.py              # 分鏡表（可選）
python3 render_video.py            # 無聲母帶 output/_build/master_video.mp4
python3 audio.py                   # 配樂、音效、混音 output/_build/mix.wav
./encode.sh                        # 輸出 preview 與 final MP4
```
