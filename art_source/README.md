# 角色插圖放這裡

檔名使用角色 id（副檔名 png / jpg / webp 皆可）：

| id | 角色 |
|---|---|
| captain | 美國隊長 |
| spider | 蜘蛛人 |
| knight | 蝙蝠俠 |
| mario | 超級瑪利歐 |
| mikasa | 米卡莎 |
| joker | Joker |
| sailor | 美少女戰士 |
| student | 史萊哲林魔法師（哈利波特） |
| elder | 鄧不利多 |

放好後執行 `npm run art`，再執行 `npm run render`。
沒有提供圖片的角色會自動使用原本的剪影版本。
提示詞請見 `docs/character_art_prompts.md`。
